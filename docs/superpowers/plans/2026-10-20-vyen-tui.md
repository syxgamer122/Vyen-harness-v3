# TUI cho CLI Vyen — Kế hoạch thực thi

> **Cho người thực thi:** plan này viết cho người chưa thấy codebase. Mỗi task là
> một vòng TDD: viết test đỏ → chạy thấy đỏ → implement → xanh → mutation chứng
> minh test thật sự canh → commit. Không gộp task, không commit khi test đỏ.

> **Trạng thái:** bản nháp. `tests/plan-traceability.test.ts` đòi mọi file test
> trong bảng "Kịch bản & Test" phải **tồn tại**, nên plan chỉ được chuyển lên
> `docs/superpowers/plans/` ở Task 9 — sau khi 9 file test đã có. Chuyển sớm hơn
> là làm `npm run test` đỏ.

**Mục tiêu:** `npm run cli` trong terminal thật mở một TUI full-screen đẹp như
OpenCode nhưng mang màu Vyen; toàn bộ vòng lặp hội thoại, transcript, nén context
và cổng duyệt hiện có được tái dùng, không viết lại.

**Kiến trúc:** `cli/index.ts` (CJS) chọn frontend → `await import('./tui/entry.tsx')`
(đảo ESM) → `createTui()` dựng renderer + React root → `runRepl()` hiện có chạy với
adapter của TUI. Plain path, `-p`, pipe không đổi.

**Stack:** TypeScript, React 19, `@opentui/core@0.6.6`, `@opentui/react@0.6.6`,
vitest 4.1.11, Node ≥ 26.4.0 cho TUI.

**Spec:** `docs/superpowers/specs/2026-10-20-vyen-tui-design.md`

## Ràng buộc chung

- Node ≥ 26.4.0 **chỉ** cho TUI; plain path phải chạy trên mọi Node repo hỗ trợ.
- Trong TUI **không** gọi `process.exit()`; dùng `renderer.destroy()`.
- Mọi file trong `cli/tui/` là ESM. Không file CJS nào static-import từ đó.
- Mọi file mới trong `cli/` phải vào `CORE_ENTRIES` **trong cùng commit**.
- Hex chỉ sống trong `cli/tui/theme.ts`. Component không tự viết mã màu.
- `note` thêm tham số mức độ là **tuỳ chọn**; plain path phải in y nguyên từng byte.
- Commit message **không dấu**; comment/tài liệu **có dấu**.
- File nguồn không BOM. Sửa file bằng PowerShell thì dùng
  `[System.IO.File]::WriteAllText` với `UTF8Encoding($false)` và đọc lại xác nhận.
- Trước khi báo xong: `npm run typecheck`, `npm run lint` (0 lỗi), `npm run test`
  (4 flaky đã biết ở AGENTS.md §1 không tính), `npm run docs:check`, `npm run check`.
- File mới phải `git add` trước khi chạy `docs:check` (checker dùng `git ls-files`).
- Không thêm dependency nào ngoài `@opentui/core` và `@opentui/react` (peer của
  chúng do npm tự cài; không khai tay nếu npm không đòi).

## Review Focus

1. **Cổng vào và đường plain không đổi.** `chooseFrontend` là hàm thuần; `-p`,
   pipe, `VYEN_PLAIN=1`, Node cũ đều rơi về plain. Plain path in ra **y nguyên**
   từng byte như trước (không có escape sequence, không có callback mới bắt buộc).
2. **Tích hợp CJS → ESM.** `cli/index.ts` không static-import `cli/tui/`; chỉ
   `await import('./tui/entry.tsx')` sau khi đã quyết định mở TUI. Import hoặc
   `createTui()` ném thì in lý do và chạy plain, **trước khi** dựng host/tool.
3. **Sự kiện tool.** Ghép call↔result theo `id` (`toolCallId`), không theo tên
   hay thứ tự. `args` được chuẩn hoá: JSON string → object, còn lại giữ nguyên
   (đường giả lập truyền chuỗi tóm tắt). Không truyền callback thì hành vi plain
   không đổi.
4. **Cổng duyệt.** Không listener ⇒ `false` ngay. Enter và Esc đều là **từ chối**.
   Esc trong hộp duyệt không được cắt lượt. Hai yêu cầu cùng lúc phải xếp hàng,
   trả lời đúng id. Mô tả đi qua `describeToolCall` (đã che bí mật).
5. **Màn hình.** Cùng một `CoreMessage[]` phải dựng ra cùng block ở lần nạp lại
   và lúc stream. Tool line một dòng, tối đa 60 ký tự, đã che bí mật. Enter gửi,
   Shift+Enter xuống dòng. Ô nhập blur khi `running`/`approval`. Màu lấy từ
   `brand/mark.json`, không copy bảng màu OpenCode.

```tsx
/** @jsxImportSource @opentui/react */
import React from 'react';
import { createCliRenderer } from '@opentui/core';
import { createRoot } from '@opentui/react';
import { theme } from './theme.ts';

export interface TuiCreateOptions { workspace: string; modelLabel: string; windowTokens: number }
export interface TuiSession { run(): Promise<void>; close(): void }

export async function createTui(opts: TuiCreateOptions): Promise<TuiSession> {
  const renderer = await createCliRenderer({ exitOnCtrlC: true });
  const root = createRoot(renderer);
  root.render(
    <box flexDirection="column" width="100%" height="100%" backgroundColor={theme.bg} padding={2}>
      <text fg={theme.text}>Vyen TUI — {opts.workspace}</text>
      <text fg={theme.muted}>esc de thoat</text>
    </box>,
  );
  let daDong = false;
  return {
    run: () => new Promise<void>((resolve) => {
      const h = (k: { name?: string }): void => {
        if (k.name === 'escape') { renderer.keyInput.off('keypress', h); resolve(); }
      };
      renderer.keyInput.on('keypress', h);
    }),
    close: () => { if (!daDong) { daDong = true; renderer.destroy(); } },
  };
}

/* Chạy trực tiếp để kiểm tay: npx tsx cli/tui/entry.tsx */
if (import.meta.main) {
  void (async () => {
    const t = await createTui({ workspace: 'dev', modelLabel: 'dev', windowTokens: 200_000 });
    await t.run();
    t.close();
  })();
}
```

`import.meta.main` là API Node ≥ 24.2; nếu tsx không đặt cờ này, thay bằng
`process.env.VYEN_TUI_DEV === '1'` và chạy `VYEN_TUI_DEV=1 npx tsx cli/tui/entry.tsx`.
